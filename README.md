# Schere-Stein-Papier

Ein kleines Konsolenspiel in Java: Du spielst gegen den Computer.

Entstanden als Übungsprojekt im 1. Semester Wirtschaftsinformatik.

## Spielregeln

- Schere schlägt Papier
- Papier schlägt Stein
- Stein schlägt Schere
- Gleiche Wahl ergibt ein Unentschieden

## So funktioniert es

1. Das Programm fragt dich nach deiner Wahl: `0` = Schere, `1` = Stein, `2` = Papier.
2. Der Computer wählt zufällig eine der drei Optionen.
3. Das Programm zeigt beide Wahlen an und sagt, wer gewonnen hat.

## Starten

1. Projekt in IntelliJ IDEA öffnen
2. Die Klasse `SchereSteinPapier` ausführen (grüner Play-Button)
3. Zahl eingeben und mit Enter bestätigen

## Verwendete Java-Konzepte

- Variablen und Datentypen (`int`)
- Eingabe mit `Scanner`
- Zufallszahlen mit `Random`
- Verzweigungen mit `if` / `else if` / `else`
- Logische Operatoren (`&&`, `||`)
